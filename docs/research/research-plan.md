# Research plan

## Questions

- Fatigue: do within-person ocular/facial/head and task features change alongside subjective fatigue during a sustained task?
- Mind wandering: do pre-probe feature windows differ between self-reported on-task and unrelated-thought episodes?
- Joint behavior: which facial/ocular/head patterns are repeatable across sessions and task contexts?

Treat these as hypotheses to test, not associations already established in this repository. Fatigue, mind wandering, sleepiness and visual attention are different constructs.

## Study sequence

Validate measurement -> pilot protocol/label usability -> repeated sessions -> exploratory statistics -> sufficient-data model evaluation. Predefine windows, primary outcomes, exclusions and plausible confounders before confirmatory analysis. A webcam is an exploratory measurement device; it is not a validated eye tracker.

Collect structured sleep, caffeine timing, eyewear, lighting category, recent screen use and task context with voluntary/unknown responses. Avoid unnecessary identifying/free-text data. Assess practice, boredom, task difficulty, dry-eye effects and tracking quality as possible alternative explanations.

## Analysis

Compare early/late task windows within person rather than assuming resting baseline and task performance are directly equivalent. Use individual plots, descriptive differences, effect sizes and uncertainty. Account for repeated observations; do not treat every frame as an independent participant.

Associate pre-probe windows with self-reports. Fatigue pre/post differences are session outcomes, not objective window labels. Separate fatigue and mind-wandering models.

ML starts with a majority/dummy baseline and Logistic Regression. Compare Random Forest/Bagging only with sufficient data. Use grouped evaluation, report per-class precision/recall/F1 and balanced metrics; ROC-AUC requires appropriate class coverage. Describe participant counts, probe counts, imbalance, exclusions and uncertainty.

## Validation and interpretation

Validate blink detection against annotated events and gaze against held-out targets. Repeat sessions to measure reliability. Record all algorithm/protocol versions. Report null results and failures; association is not causal proof.

Consent and privacy are required for collection. Before formal recruitment/publication, determine applicable institution ethics requirements. No ADHD diagnosis/probability or medically actionable conclusions are generated by this project.
