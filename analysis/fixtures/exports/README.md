# Synthetic V1 export fixtures

These JSON files mimic Focus Lab / NeuroLens collection schema `1.0.0` so the offline adapter can be tested without real participant records.

They are **not** empirical evidence, **not** camera-validated, and **not** interchangeable with a researcher-exported production file. Planted `participant_id`, `user_agent`, notes, events and withdrawal tokens exist only so tests can prove those fields never appear on evidence artifacts.

Do not add real exports, identifiable data, or production D1 dumps here.
